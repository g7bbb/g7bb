# 곤충 배틀 베타

사진을 올리면 2D 곤충으로 변신하고, 그 곤충으로 환경 생존 배틀을 하고, 랭킹을 확인하는 체험용 웹앱입니다.
핸드폰 브라우저로 접속해서 쓰는 것을 전제로 만들었습니다.

## 지금 상태

4가지 기능 코드는 전부 작성되어 있습니다. 아직 안 한 것은:

1. 실제 계정 3개 만들기 (Google AI Studio, Supabase, Vercel)
2. `.env.local` 파일에 키 값 채워넣기
3. Node.js 설치 후 로컬에서 실행해보기
4. Vercel에 배포하기

아래 순서대로 따라오시면 됩니다.

---

## 1단계. 필요한 계정 만들기

### (1) Google AI Studio — 곤충 이미지 생성용 API 키

1. https://aistudio.google.com 접속 후 구글 계정으로 로그인
2. "Get API key" 메뉴에서 새 API 키 발급
3. 발급받은 키를 메모해두기 (예: `AIza...`로 시작하는 문자열)

### (2) Supabase — 회원 아이디 / 랭킹 저장용 데이터베이스

1. https://supabase.com 접속 후 가입, 새 프로젝트 생성 (이름은 아무거나, 예: `insect-battle`)
2. 프로젝트가 만들어지면 왼쪽 메뉴 **SQL Editor** 클릭
3. 이 저장소의 [supabase/schema.sql](supabase/schema.sql) 파일 내용을 전부 복사해서 붙여넣고 **Run** 클릭
   → `players`, `insects`, `battles` 3개 테이블이 만들어집니다
4. 왼쪽 메뉴 **Project Settings → API** 에서 "Project URL" 과 "anon public" 키를 복사

### (3) 카카오톡 채널 링크

이미 운영 중인 카카오톡 채널의 공유 링크(예: `https://pf.kakao.com/_xxxxx`)를 준비해주세요.
없다면 카카오톡 채널 관리자센터(https://center-pf.kakao.com)에서 채널을 먼저 만들면 됩니다.

## 2단계. 환경변수 파일 만들기

이 폴더에 있는 `.env.local.example` 파일을 복사해서 이름을 `.env.local` 로 바꾸고,
1단계에서 얻은 값들을 채워넣으세요.

```
GEMINI_API_KEY=여기에_구글AI스튜디오_키
GEMINI_IMAGE_MODEL=gemini-2.5-flash-image
NEXT_PUBLIC_SUPABASE_URL=여기에_Supabase_프로젝트_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=여기에_Supabase_anon_key
NEXT_PUBLIC_KAKAO_CHANNEL_URL=여기에_카카오톡_채널_링크
```

`.env.local` 파일은 절대 깃허브에 올리면 안 됩니다 (이미 `.gitignore`에 등록되어 있어서 자동으로 제외됩니다).

> 참고: `GEMINI_IMAGE_MODEL`은 구글이 모델 이름을 자주 바꾸기 때문에 별도 환경변수로 뺐습니다.
> 이미지 변환이 안 되면 가장 먼저 이 값이 최신 모델명인지 https://ai.google.dev 에서 확인해보세요.

## 3단계. 내 컴퓨터에서 처음 실행해보기

Node.js가 설치되어 있지 않아서 먼저 설치가 필요합니다.

1. https://nodejs.org 에서 **LTS** 버전 다운로드 후 설치 (기본 설정 그대로 "다음"만 누르면 됩니다)
2. 설치가 끝나면 터미널(PowerShell)을 새로 열고 이 프로젝트 폴더로 이동
3. 아래 명령 순서대로 실행

```bash
npm install
```

```bash
npm run dev
```

4. 터미널에 나오는 주소(보통 `http://localhost:3000`)를 브라우저에서 열면 앱이 보입니다

이후에는 저에게 "실행해줘" 또는 "테스트해줘"라고 말씀해주시면 제가 대신 실행하고 화면을 확인해서 결과를 보여드릴 수 있습니다.

---

## 4단계. Vercel로 배포해서 핸드폰으로 접속하기

1. https://vercel.com 가입 (GitHub 계정으로 가입하는 게 가장 쉽습니다)
2. 이 프로젝트를 GitHub 저장소로 먼저 올려야 합니다 (제가 도와드릴 수 있어요, 말씀해주세요)
3. Vercel에서 "Add New → Project" 로 그 GitHub 저장소를 선택
4. 배포 설정 화면에서 **Environment Variables** 항목에 `.env.local`에 있는 값들을 그대로 하나씩 입력
5. Deploy 클릭 → 몇 분 뒤 `https://프로젝트이름.vercel.app` 같은 주소가 생김
6. 이 주소를 핸드폰으로 열면 바로 접속됩니다 (QR코드로 만들어서 행사장에 붙여두면 편합니다)
