# 손글씨 효과 글씨 만들기

Jin 이 직접 쓴 글씨를 배틀 효과 글씨로 쓰기 위한 도구입니다. (2026-09-29)

## 왜 폰트가 아니라 이미지인가

한글 폰트는 최소 2,350자를 써야 해서 행사(10/3) 전에는 불가능합니다.
필요한 건 **13개 단어**뿐이라 통글씨를 이미지로 쓰는 쪽이 작업량도 적고
**결과도 더 자연스럽습니다** — 폰트로 찍으면 `흔들흔들` 의 `흔`·`들` 이
도장처럼 똑같이 두 번 나와 손글씨의 불규칙함(=매력)이 사라집니다.

## 쓰는 법

```bash
pip3 install Pillow numpy
python3 tools/handwriting/extract.py 사진.jpg public/fx/퍼펙트.png --rotate-left
```

## Jin 이 쓰는 방법

**Zen Brush 앱(무료판)** 으로 씁니다. 가로 모드가 없어서 **글씨를 옆으로 눕혀서** 쓰고,
`--rotate-left` 로 세웁니다. 워터마크는 자동으로 지워지니 신경 쓰지 않아도 됩니다.

- ✅ 굵은 검정 붓 / 글자끼리 띄우기 / 긴 말은 2칸으로 나눠 쓰기
- ❌ 연필·볼펜(회색이라 배경 제거가 지저분해짐), 글자 겹쳐 쓰기

## 필요한 13개

**① 필살기 이름 (8)** 큰턱공격! · 씨름선수! · 당랑권! · 나비처럼 날아 벌처럼 쏜다! ·
흔들흔들 회피! · 웅크리기! · 바위처럼!! · 공격!!

**② 타이밍 판정 (4)** 퍼펙트! · 그레이트! · 굿! · 발동!

**③ 타격 (1)** 콰쾅!

## 출력 형식 — ⚠️ 색을 구워 넣지 않습니다

`RGB=흰색, 알파=먹물` 로 저장하고 CSS `mask-image` 로 씁니다.
기술마다 글자 색이 달라서(빨강·금색·하늘색…) 색을 넣어버리면 색깔별로 다시 써야 합니다.

```css
mask-image: url(/fx/퍼펙트.png);
mask-size: contain;
background: currentColor;   /* 색은 여기서 */
```
