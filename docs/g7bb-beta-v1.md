## 2. 종이(참가권)

- 종이는 **A 한 종류**만 인쇄. 번호 `A-001`~ + **비밀번호 4자리**(번호에서 HMAC 계산, `lib/ticket-pin.ts`).
  ⚠️ 그 안의 SECRET 은 인쇄 후 **절대 바꾸지 말 것** (뽑은 종이 비밀번호가 전부 틀려짐).
- 참가 QR = `https://g7bb.vercel.app/start?t=A-014&k=1234` (화면 주소와 무관하게 `SITE_URL` 로 고정).
- 화면에는 `A` 를 빼고 `014` 처럼 숫자만 보여줌. 손으로 넣을 땐 번호 + 비밀번호.
- 번호 구간: **900~999 = 테스트**(테스트끼리만 만남, 횟수·대기 없음) · **450~500 = 직원 캐릭터**(손님 순서에서 빠짐, 시상 때 랭킹에서 뺄 것).
- 금액은 종이가 아니라 직원이 `/admin/tier` 에서 올려줌 (안 올리면 1.5만원).

### 참가권 (10/4 아침 최종, `lib/tiers.ts`)
| 글자 | 금액 | 게임 | 중간보스·보너스 | 그 밖 |
|---|---|---|---|---|
| A | 1.5만원 | 1게임(3판) | 15% | 30분 대기·데이터 보존 안 됨·랭킹 2위·1위는 못 이김(화면 안내 없음) |
| B | 2만원 | 3게임(9판) | 매 게임, 첫 번째는 보너스+레벨 1 업 | 대기 없이 연달아(`/next-game`), 캐릭터 보존 |
| C | 5만원 | 하루 6게임 | B 와 같음 | 첫날만, 금장식 카드, 피규어·포스터 배송 |
| D | 10만원 | 2일 무제한 | B 와 같음 | 다이아 카드, 4분기 체험 2회 |
- 직원 "➕ 1게임 더" = 1.5만원 1게임 추가 (금액 등급은 그대로).
- 게임마다 연습 1판(경험치 50%, 점수 안 남음).

## 3. 부스 기기 설정

### 아이용 태블릿 (첫 화면 `/`)
| 항목 | 값 |
|---|---|
| 들어오는 길 | 종이 QR 을 카메라로 찍기, 또는 첫 화면 **"📷 종이 QR 찍고 시작하기"** (구형 태블릿용, 앱 안에서 jsQR) |
| 아무도 없을 때 | 60초 안 만지면 **홍보 영상** 자동 재생, 누르면 멈춤 (`ATTRACT_AFTER_MS`) |
| 화면 꺼짐 | 아무도 로그인 안 했을 때 **화면 안 꺼짐**(Wake Lock). 안 되는 기기는 태블릿 설정에서 화면 꺼짐 시간을 길게 |
| 게임 끝 로그아웃 | 랭킹 도전이 끝나면 **90초** 뒤 자동 로그아웃 + 첫 화면 (`AUTO_SIGNOUT_MS`) |
| 무입력 로그아웃 | **3분** (곤충 만들기·이름 쓰는 화면은 **8분**), 마지막 30초 "👀 아무도 없어?" 경고 |
| 직원이 바로 끝내기 | 첫 화면 "👋 ○○ 끝내기 (다음 친구 차례)" · 직원 메뉴 "👋 이 기기의 아이 로그아웃" |
| 쓰던 거 임시 저장 | 그 기기 localStorage 에 번호별 6시간 (탭이 꺼져도 같은 QR 로 오면 이어서) |
| 화면 크기 | 터치 + 폭 600px 이상이면 글자를 화면 폭에 맞춰 키움(최대 26px). 820×1180 태블릿 기준으로 맞춤 |
| 글씨 | 폰은 기본보다 10% 크게 |
| 소리 | 첫 터치 때 켜짐. 오른쪽 아래 🎵/🔇. **아이폰 무음 스위치가 켜져 있으면 웹은 소리를 못 냄** |

### 모니터 (`/live` 실시간 랭킹)
- 가로 약 20cm(760px) 창 크기에 맞춤. 1~50위, 1~3위 그림.
- 20초마다 순위 다시 받기 · 10분마다 화면 새로고침 · 한 바퀴마다 3→2→1위 카드 0.8초씩.
- 흐르는 속도 1~3위 32 · 4~10위 56 · 11위~ 84 px/초.

### 노트북 (`/attract` 홍보 영상)
- 1366×768 기준. 39초 반복 (제목 → 배틀 → 카드 행진 → TOP 3 → 시작 안내). 누르면 첫 화면.
- 15분마다 카드 다시 받기 · 10분마다 새로고침 · 화면 안 꺼짐.

### 직원 화면 (`/admin`, 암호 `ADMIN_CODE`, 기기에 기억)
| 메뉴 | 주소 | 쓰임 |
|---|---|---|
| 참가권 | `/admin/tier` | 번호 찾기 → 금액 올리기 · 1게임 더 · 30분 대기 풀기 · 비밀번호 보기 |
| 포스터·카드 | `/admin/poster` | 원본 그림 받기 · A3 포스터 · 셀피 카드(캐논 CP1500, 54×86mm) |
| 사생대회 심사 | `/admin/judge` | 예쁜 곤충 1~4위 |
| 실시간 랭킹 | `/live` | 모니터용 |
| 용지 인쇄 | `/print` | 종이 뽑기 (`?count=300&start=0`) |

## 4. 행사 중에 실제로 생긴 문제와 대응

| 언제 | 증상 | 원인 / 대응 |
|---|---|---|
| 10/3 | 구형 태블릿이 QR 을 못 읽음 | 앱 안 QR 스캐너 추가 |
| 10/3 | 게임이 끝났는데 로그아웃이 안 됨 | 연습 1판이 남으면 "아직 할 게 있다" 로 봄 → 랭킹 도전 기준으로 바꿈 |
| 10/3 | 퍼펙트 글자가 안 보임 | 판정 글자를 보여주기 전에 화면이 넘어감 → 순서 바꿈 |
| 10/3 | 쓰던 글이 날아감 | 카메라 열 때 브라우저가 탭을 꺼버림 → 임시 저장 |
| 10/3 | 1판만 하고 나가면 남은 판이 사라짐 | 판 수를 DB 에 적고 이어하기 |
| 10/4 | 순위판이 옛 화면 그대로 | 10분마다 새로고침 추가 |
| 10/4 | 그림 변환 402 | Gemini 선불 크레딧 소진 → 충전, 402 전용 안내 |
